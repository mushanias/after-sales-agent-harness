# 声途 HiFi 店售后处理规则

> 这是商家交付给客服团队使用的模拟店规，适用于声途 HiFi 店销售的耳机、耳放和随单配件。
> 订单实时状态以订单系统查询结果为准；本文件只描述处理规则，不代表某笔订单已经受理。

## 一、取消订单与物流拦截

1. 订单尚未发货时，可以申请取消。仓库锁单后是否能够取消，以仓库实际处理结果为准。
2. 订单已经交给承运商后，客服只能申请物流拦截，不能承诺一定拦截成功。
3. 拦截失败的，消费者需要先正常签收，再按照适用的退货规则处理；拒收产生的额外运费由客服根据责任原因确认。

## 二、七天无理由退货

1. 七日期间从签收次日开始计算，消费者需要在期限内提出申请。
2. 未拆封且商品、包装、配件、说明书、保修卡和赠品齐全的，可以申请七天无理由退货。
3. 头戴式耳机、耳放仅为查验进行拆封或短时间试听，没有划痕、污渍、异味及其他明显使用痕迹，序列号和包装完整的，可以继续按商品完好处理。
4. 入耳式耳机如果已经拆开一次性密封耳塞包装，且购买页面曾显著提示并由消费者确认其卫生属性，按店铺公示规则不支持七天无理由退货。无法确认是否提示并勾选时，客服不得直接拒绝，需要转人工核实订单留痕。
5. 非质量原因退货，寄回运费由消费者承担；店铺包邮订单不另外扣除首次发货的普通运费。
6. 发起申请不等于退款到账。仓库验收退回商品后才进入退款审核，退款原路退回，具体到账时间以支付渠道为准。

## 三、质量问题

1. 出现单边无声、持续杂音、无法充电、连接频繁中断等功能故障时，先确认设备、连接方式、复现步骤以及是否更换设备测试。
2. 签收后七日内反馈并经检测确认属于商品质量问题的，可以申请退货或换货；第八日至第十五日确认质量问题的，可以申请换货。
3. 超过十五日但仍在一年保修期内的主商品，优先进入检测维修。人为进液、摔落、私自拆机、非正常供电造成的损坏不在免费保修范围内。
4. 质量问题经确认后，店铺承担必要的寄回运费。未经确认自行使用到付或高价快递的，超出普通快递标准的部分不保证承担。
5. 当前 Agent 没有检测、换货和维修执行能力，只能收集信息并说明下一步，不能声称已经创建检测单、换货单或维修单。

## 四、错发、漏发和运输破损

1. 收到的型号、颜色或数量与订单不一致时，需要核对订单号、外包装面单、实收商品及配件照片。
2. 外包装明显破损、商品受压或进水时，应保留外包装和面单，并提供能够说明问题的照片或视频。
3. 缺少赠品或配件时，需要说明缺少的具体物品。开箱视频可以帮助核实，但不能仅因消费者没有开箱视频就直接拒绝受理。
4. 错发、漏发和运输破损需要人工核实责任。当前 Agent 不得承诺补发时间、赔偿金额或物流处理结果。

## 五、客服判断边界

1. 先查询订单，再使用本规则判断；用户描述与订单系统冲突时，以系统事实为锚点，并向用户说明冲突。
2. 缺少签收时间、商品状态、故障表现或购买时确认记录时，先询问，不得自行补全。
3. 店规与适用法律法规冲突时，以法律法规为准；无法判断冲突时转人工处理。
4. 知识中写有某项服务，不代表当前 Agent 能够执行。没有对应工具时，只能解释规则、收集材料和给出下一步。

## 六、典型案例

### 案例 A：未拆封退货

消费者签收第三天提出退货，外包装未拆，商品和赠品齐全。客服查询订单并确认签收日期后，可以告知其符合七天无理由申请条件；消费者承担寄回运费。只有消费者明确要求发起申请后，才执行退款申请工具。

### 案例 B：头戴式耳机试听

消费者签收第五天，拆封试听约十分钟，称商品无划痕、无污渍，包装和配件齐全。拆封本身不能作为拒绝理由，应继续确认商品完好情况；确认信息足够后再判断是否可以申请。

### 案例 C：拆封入耳式耳塞

消费者签收第二天，已经拆开一次性密封耳塞包装。客服还需要确认购买页面是否显著提示卫生属性并由消费者勾选确认。查询不到确认留痕时不能直接拒绝，应说明需要人工核实。

### 案例 D：运输中要求取消

订单已经发货，消费者要求立刻退款。客服可以说明当前只能申请物流拦截且结果不确定；由于当前 Agent 没有拦截工具，不得回复“已经拦截”或调用七天无理由退款工具。

### 案例 E：单边无声

消费者签收第十天反馈左耳无声。客服需要询问设备、连接方式、复现情况和交叉测试结果。这属于质量问题换货判断，不属于七天无理由退款；当前 Agent 只能收集材料并引导人工检测。
